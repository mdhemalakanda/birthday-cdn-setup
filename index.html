✦ Birthday Page · Quick Setup ✦

One small step in Rocket.net 🎈

The birthday page is live and shows a personal name for every visitor. Your server cache must skip this one page — otherwise the cache saves the first visitor's name and everyone sees the same one. It takes about 2 minutes.

1 The page is live — take a look

Open this link and change the name at the end of the URL to see it update instantly:

yourwebsitecouldtalk.com/birthday/?name=Sarah

Every section is already working — the Talking Orb, the call button, the video and the affiliate button. Only this cache setting remains. 🎉

2 Why the cache must skip this page

The personal name is added when the page loads, separately for every visitor. If your server cache saves the finished page, the first visitor's name gets frozen for everyone who opens it after them.

Excluding this single page costs nothing — images, styles and scripts stay cached exactly as before.

3 Add the exclusion in Rocket.net

  1. Log in to my.rocket.net (your hosting dashboard).
  2. Open the site yourwebsitecouldtalk.com.
  3. Go to the Rocket CDN / Cache section.
  4. Find Cache Exclusions (sometimes called “Never cache URLs” or “Bypass Cache”).
  5. Add the line below and save.
  6. Click Purge Cache once.
/birthday*

The star at the end covers the page plus every version of it (?name=Sarah, ?name=John, ad tracking parameters — all of them).

IF YOU MANAGE CLOUDFLARE DIRECTLY — OPTIONAL

Add one Page Rule in the Cloudflare dashboard:

*yourwebsitecouldtalk.com/birthday* → Cache Level: Bypass → Save and Deploy.

4 The 2-minute test

Open these two links in two separate incognito windows:

Window 1 — should show
Alpha
/birthday/?name=Alpha
Window 2 — should show
Beta
/birthday/?name=Beta
✅ Window 2 shows “Beta” → everything is working. All done!
❌ Window 2 shows “Alpha” → the exclusion has not been saved yet. Repeat step 3 and purge again.

5 Ready-to-share birthday links

Once the test passes, share birthday links like these:

yourwebsitecouldtalk.com/birthday/?name=Your-Name-Here

Hyphens between words become spaces on the page, so ?name=Happy-Birthday-Sarah displays “Happy Birthday Sarah”. The page works beautifully on phones too — perfect for WhatsApp birthday messages. 🎈
